# Side-B

좋아하는 곡이나 지금의 분위기에서 출발해, 닮았지만 덜 알려진 음악을 찾는 Chrome 확장 프로그램이다.

현재 버전: `v1.0.0`

## 주요 기능

- **방향별 음악 추천**: 곡을 검색하면 `닮은 곡`, `덜 알려진 닮은 곡`, `숨은 발견`을 보여 준다. 분위기를 검색하면 `닮은 곡`, `반대 무드`, `숨은 발견`으로 나눠 추천한다.
- **현재 곡으로 추천**: YouTube Music에서 재생 중인 곡을 바로 검색어로 쓸 수 있다.
- **플레이리스트 저장**: 추천 결과를 확인한 뒤 새 비공개 YouTube Music 플레이리스트를 만들거나 기존 플레이리스트에 곡을 추가한다.
- **자동 EQ**: 미리듣기 음원에서 분류한 장르에 맞춰 YouTube Music 탭에 5밴드 EQ를 적용한다.

## 설치

Chrome 116 이상이 필요하다.

1. 전달받은 `Side-B-1.0.0.zip`의 압축을 푼다.
2. Chrome 주소창에 `chrome://extensions`를 입력한다.
3. 오른쪽 위의 `개발자 모드`를 켠다.
4. `압축해제된 확장 프로그램을 로드합니다`를 누른다.
5. 압축을 푼 `Side-B-1.0.0` 폴더를 선택한다.

저장소에서 직접 설치할 때는 `extension` 폴더를 선택한다. 인증 번들이 들어 있으므로 따로 빌드하지 않아도 된다.

## 사용법

1. YouTube Music 탭을 열고 Side-B 사이드 패널을 실행한다.
2. 처음 실행할 때 `Google로 계속하기`로 로그인한다. 기본 서버는 허용 목록에 등록된 계정만 쓸 수 있다.
3. `아티스트 - 곡명` 또는 원하는 분위기를 입력하고 `찾기`를 누른다. 재생 중인 곡을 기준으로 찾으려면 `현재 곡으로 추천`을 고른다.
4. 추천 방향 탭에서 결과를 확인한다. 매칭이 의심스러운 곡은 `YT Music` 링크로 직접 들어 볼 수 있다.
5. `N곡 플레이리스트로 내보내기`를 눌러 새 플레이리스트를 만들거나 기존 플레이리스트에 추가한다.
6. YouTube Music 탭에서 `EQ 적용`을 켠다. 재생 곡이 바뀌면 장르에 맞는 EQ도 자동으로 갱신된다.

화면별 사용법과 문제 해결 방법은 [확장 프로그램 README](extension/README.md)에 정리돼 있다.

## 프로젝트 구성

| 경로 | 기술과 용도 | 문서 |
|---|---|---|
| `extension/` | Manifest V3 기반 Chrome 사이드 패널. 추천 조회, YouTube Music 내보내기, 자동 EQ 제공 | [확장 프로그램 README](extension/README.md) |
| `backend/` | FastAPI 백엔드. 추천 계산, 미리듣기 탐색, YouTube 매칭, 인증과 AI 추론 중계 담당 | [백엔드 README](backend/README.md) |
| `inference/` | CLAP 임베딩과 SVM을 사용하는 비공개 장르 분류 서비스 | [AI 추론 README](inference/README.md) |
| `deployment/` | Cloud Run 서비스 설정, 배포 스크립트와 배포 계약 테스트 | [백엔드 배포 안내](backend/README.md#배포) |

구조, 실행 방법, 설정, 테스트와 운영 시 주의사항은 각 하위 README에서 확인할 수 있다.

## 권한과 데이터 처리

- Google 로그인은 Side-B 백엔드 인증에 쓴다.
- YouTube 권한은 사용자가 확인한 곡을 자신의 플레이리스트에 저장할 때만 요청한다.
- 사용자의 YouTube OAuth 토큰과 캡처한 탭 오디오는 Side-B 백엔드로 보내지 않는다.
- 자동 EQ는 탭 오디오 자체가 아니라 백엔드가 찾은 30초 미리듣기 음원을 분석한다.
- Chrome 권한을 어디에 쓰는지는 [확장 프로그램 권한 안내](extension/README.md#권한)에 적어 두었다.
